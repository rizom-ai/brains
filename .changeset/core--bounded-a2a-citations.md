Add bounded A2A source artifacts without enabling guest network tools or changing inbound opt-in, admission, spending policy, or deployment settings. Interfaces receive a narrow `publicSources.resolve(references, signal)` reader: at most twenty local references, public/published reads, configured citation eligibility, current titles and canonical HTTPS links, detached frozen results, and shutdown/caller cancellation checks. A2A rechecks stored references on polling and replay rather than treating cached citation text as publication authority.

The outbound client bounds source, artifact, event, frame, response and read counts, refuses redirects and cross-origin source links, and binds attribution to the contacted HTTPS peer rather than supplied brain/provenance claims. This verifies transport origin, not the truth or publication status of a remote peer's assertions. It does not promote arbitrary tool source arrays, authorize guest network calls, guarantee atomic publication snapshots, or bound spending or total process memory.
