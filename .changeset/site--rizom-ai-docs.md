rizom.ai can carry the documentation that lives on docs.rizom.ai. With the docs and guides plugins on the brain, `/docs` is the docs index (its opening, the guides, then every section's docs) and each doc and guide has its own page at `/docs/<slug>` and `/guides/<slug>`, inside rizom.ai's chrome; a visitor's answer may cite them. The docs' own footer, which carries docs.rizom.ai's theme toggle, stays hidden under rizom.ai's. Without the plugins nothing changes.
