The unauthenticated `/health/operate` endpoint and the public status tools now carry health fields only. Its `app` block holds the version, uptime and each daemon's name, plugin, status and health status with its last check time; background work stays in the readiness checks and queue and worker signals of the same response. Anonymous callers no longer see per-type entry counts, entity and embedding totals, the brain and AI model names, endpoints, interactions, or the message and details a daemon reports, which could name the admin-only preview host. A public caller of `system_status` gets the version, uptime, background work and the web surfaces it can open, without the model or totals, and a public caller of `system_job_status` gets job and batch progress without the raw batch errors. Operators still find all of it on authenticated surfaces: `system_status` as a trusted or admin caller over MCP keeps the model, entity and embedding totals, `system_job_status` keeps batch errors for trusted and admin callers, `system_analytics` reports per-type counts at the caller's access, and Studio reads app info in-process as before. The directory-sync stress harness in `@rizom/ops` now reads its note and entity counts from the runtime's database over SSH.
