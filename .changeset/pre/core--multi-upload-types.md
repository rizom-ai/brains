Several files uploaded in one chat message are each saved as the type asked for. Several essays become several posts under one confirmation, each with the publication date and canonical address stated for it; a text upload saved as a post (or another type that keeps your text) takes the file's text as its own, as pasted text does. Several PDFs kept as notes have their text extracted into each note, with or without Markdown files beside them, instead of being kept as documents. The confirmation lists each file's title, type and stated fields. A PDF asked to become a post is refused with what it can be saved as.
