A site can declare the languages it is built in: `defineSite({ languages: ["en", "zh-TW"] })`, the first the default. Language tags are validated, a language declared twice is refused, and so is a route under another language's path. `languagePath(language, defaultLanguage, path)` gives where a page lives in a language: the default keeps the route's own path, every other language puts its lowercased tag in front (`/zh-tw/about`). Layouts receive the page's `language` and its `alternates` (`SiteAlternate`: every language the page is built in, with its path there), for a language switch that offers only what exists. A route can carry its head and navigation label in the other languages (`translations: { "zh-TW": { title, description, navigationLabel } }`), and site metadata its title, description, copyright and call to action (`translations`, `SiteMetadataTranslation`). A section can be drawn another way in another language: `defineSection(schema, Component, { …meta, components: { "zh-TW": ComponentZh } })`; both drawings read the same copy fields.
