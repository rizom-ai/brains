A first-party create route can hand a request on to the ordinary create, as an entity plugin's interceptor continued it: unchanged, or with the title and content the route completed. The brain performs it as `system_create` performs any direct create, at the caller's authority, choosing the id from the title and making it unique. First-party definitions also build their rendered templates with the internal template builder. Both are internal to the brain's own packages; a route that is not run by the brain's runtime cannot hand off.
