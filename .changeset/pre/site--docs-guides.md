The docs site displays each guide at `/guides/<slug>` and the guides index at `/guides`, and its home shows a "Moving in" band of guides between the hero and the sections. Without the guides plugin or any guide, the home has no band. Guides stay out of the site navigation; the docs header links to them. Requires `@rizom/brain` 0.2.0-alpha.612 or later, which ships the guides plugin and the composed docs home.
