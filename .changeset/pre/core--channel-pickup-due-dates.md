The channel pickup gives a card the due date the messages name ("by Wednesday", "end of the month"), resolved from the day the message was written, and moves or clears it when later messages do; a card whose messages name no date gets none. A message that changes one of the channel's cards no longer also adds it as a new card, and a card changed twice in one batch ends as the latest message says.
