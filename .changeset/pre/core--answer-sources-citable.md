A visitor's answer lists only the pieces of work a site marks `citable` in its entity display: on the professional site, essays, presentations and projects — the pieces that light up on the homepage atlas. Topics, series, links and social posts no longer appear as sources next to the essays they point at. A site that marks no type keeps citing any type it has pages for. A site override that relabels a type now keeps the base site's other display settings for it instead of replacing the whole entry.
