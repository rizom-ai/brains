A guide can name the door of a docs homepage it belongs under: `door: use`, `run` or `extend` in its frontmatter. Absent, it reads as null, and sites that list guides on their own ignore it. The Brains documentation guides set it: the writer, researcher, consultant and team guides under using a brain, the self-hosting guide under running one.
