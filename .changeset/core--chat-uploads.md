Several files attached to one chat message are kept together: the brain proposes all of them in one confirmation, listing each file's title and type, and one confirmation saves them all. A file that cannot be saved does not stop the others, and the reply names what was saved. An uploaded note is titled by its first `#` heading, else its file name; a title the user states still wins, and the confirmation names the title the note is saved under. An uploaded file's own frontmatter is folded into the note's frontmatter instead of being left in its body. A retry after a failed upload or generation replaces the failed entry it left behind instead of being refused as already existing, when the caller may delete it. A request to change a saved note no longer generates a duplicate "-2" note beside it; the brain is pointed to update the note itself. An attached file is saved through its upload, not re-read from the chat text, and a bare "save it" right after a summary of an upload saves the summary. The reply to a confirmed save says what was saved ("Completed: Saved note …"), and while its content is still being processed, that it is saved; only a generation says its draft is generating.
