A site's section templates write the compact layout, and at start the site builder brings every section's saved copy to it quietly, exported in one commit. A copy in the older sectioned layout still reads as before, a heading its section does not name ignored; one with such a heading is left as written and reported rather than written without it. A site whose own bundle carries an older formatter is left as it is.
