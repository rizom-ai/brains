A site that declares more than one language is built in each of them. Every route is built in the default language at its own path, and again under each other language's path (`/zh-tw/about`) from copy saved for that language as `site-content/<tag>/<route>/<section>.md`. A page is built in a language only once every section on it has copy in that language, never from the default language's copy; routes fed by a datasource stay in the default language. Each page's `<html lang>` is its language. A page built in more than one language links every version of itself with `hreflang` and `x-default` as absolute URLs from the build's public URL, the sitemap lists every version, and a translated page's navigation lists the pages built in its language at their paths. site-info takes a `translations` block with the site's title, description, copyright and call to action per language; a language is built only once site-info has its block, and its pages wear that chrome. A translated page's head and navigation label come from its route's translation, else the site's title in that language.
