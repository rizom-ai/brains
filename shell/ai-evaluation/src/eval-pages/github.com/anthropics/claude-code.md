# Claude Code

Claude Code is an agentic coding tool that lives in your terminal, understands your codebase, and helps you code faster by executing routine tasks, explaining complex code, and handling git workflows, all through natural language commands. Use it in your terminal, your IDE, or tag @claude on GitHub.

## Get started

1. Install Claude Code with the native installer or through npm.
2. Navigate to your project directory and run `claude`.

## Plugins

The repository includes several Claude Code plugins that extend functionality with custom commands and agents, documented in the plugins directory.

## Reporting bugs

Use the `/bug` command to report issues directly within Claude Code, or file a GitHub issue.

## Data collection, usage, and retention

When you use Claude Code, feedback such as usage data and conversation data is collected under Anthropic's commercial terms and privacy policy, with limited retention periods for sensitive information.
