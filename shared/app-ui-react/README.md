# `@brains/app-ui-react`

Shared controls for Brain applications. Studio and Web Chat consume this package; the shared operator renderer also reuses its compiled buttons and confirmation modal while retaining its action and form contracts. Public sites and Dashboard retain their own composition and transport contracts.

Controls read only the semantic `--console-*` token vocabulary. StyleX is compiled by each app's Bun build into static CSS, while Radix supplies dialog, menu, select, switch, and tab behavior. No theme values, style injection, or application state live here. Confirmations retain server-rendered content and portal to the viewport on the client, preserve pending guards, accept custom confirmation classes, and dismiss outside only when the caller explicitly enables that policy. Buttons bound and wrap long labels, preserve native disabled behavior, and disable transitions and primary hover movement under reduced motion. Buttons, inputs, textareas, and native selects accept `xstyle` to merge caller-owned StyleX declarations with their base styles; use this instead of concatenating competing atomic classes. Native classes and inline styles remain supported, including dynamic StyleX variables. Disclosure sheets accept an explicit `triggerVariant="link"` for subordinate row actions while retaining their dialog, focus, and dismissal behavior.
