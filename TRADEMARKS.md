The Rizom Brains source code is open source (see [LICENSE](LICENSE)), and nothing
in this document limits any right the code license grants. The Rizom names and
logo are trademarks, and the name does not travel with the code.

The marks include "Rizom", "Rizom Brains", the Rizom logo, and the
"Rizom Certified" and "Rizom Certification candidate" designations. They are
held by Rizom B.V., to be assigned to the independent Rizom Foundation upon its
establishment.

**Always fine, no permission needed:** truthful descriptive use — "built on
Rizom Brains", "compatible with Rizom Brains", offering services to deploy or
operate Rizom Brains under your own brand, writing and speaking about the
project, and redistributing unmodified official builds with attribution.

**Forks and modified versions:** you may fork and modify freely under the code
license, but ship the result under your own name — not "Rizom" in the name,
logo, domain, or package names. Saying it is "a fork of Rizom Brains" is fine,
because it is true. Lexicon extensions live in a namespace you control and must
not redefine `ai.rizom.brain.*`.

**Reserved:** the "Rizom Certified" designations may be used only by partners
currently listed in the certification registry. Using "Rizom" in a company,
product, or domain name that implies affiliation requires permission — ask at
trademarks@rizom.ai; the default answer to good-faith community requests is yes.

The full, current policy is published at <https://rizom.ai/trademarks> — that
version governs. This file is a summary for convenience and is not the
authoritative text.
