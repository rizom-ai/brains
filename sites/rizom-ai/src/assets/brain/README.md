# Brain landing-page captures

These are static captures, not live product widgets or evidence of an agent run.

- `chat-*`: Studio rebuilt at revision `2b7ecfe604`, with fictional, in-memory pilot notes and a seeded conversation. Nothing was generated by a running Brain, saved to app data or published during capture. Native desktop and mobile views are provided in Instrument and Paper climates.

The source PNG bytes are embedded losslessly in self-contained SVG files because the site package’s static-asset contract is text-based. No capture content was altered by this packaging. Each image remains independently addressable and opens at full resolution. Provenance is recorded here; the landing-page caption is optional.

The Brain landing page uses the local datasource-backed proximity map, not a network capture. Retired network captures remain local, uncommitted review artifacts and are not registered as site assets. Do not seed capture contents into the app or describe these illustrative Studio captures as live.

Original sources and capture provenance are retained in the local design study under `docs/design/rizom-brain-page` in the main development checkout.
