# Peer-brain directory

Team Brain calls peer brains through explicit local agent records.

- `discovered` agents are visible for review but not callable.
- `approved` agents are allowed for A2A calls.
- `archived` agents remain historical and should not be called.

Skill records describe what this Team Brain instance can advertise in its Agent Card and what peer brains can be selected for.
