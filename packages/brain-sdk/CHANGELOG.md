## 0.2.0-alpha.795

### Minor Changes

- [#1076](https://github.com/rizom-ai/brains/pull/1076) [`fd4b85e`](https://github.com/rizom-ai/brains/commit/fd4b85e54f30fdfdfb84a8485d23c0d95dc480c9) Thanks [@yeehaa123](https://github.com/yeehaa123)! - Studio opens on Home, and the event log moves to History.

  - Home replaces Overview. It opens on one sentence that says how much needs you, and a box that saves a note or asks Chat. Below are three bands. "Needs you" lists only what waits, each item with the verb that clears it. "Continue" brings back recent drafts and conversations, and "Recently published" lists what went out. The brain's health is one line at the bottom, linking to History.
  - Workspaces can say what needs the person. A registration's `attentionProvider` (or a declarative workspace's `attention`) returns items with a title, detail, severity and the verb that opens the page that clears them. The inbox and Administration provide theirs. A plugin that provides its own items keeps its dashboard widget out of "Needs you". Home's sidebar count is the number of items it lists.
  - History, under Brain, keeps what happened over the last week instead of the last day. Repeated saves of one entry read once, and a run of the same change reads as one line.
  - Overview's 24-hour timeline and its column of widgets are gone.

## 0.2.0-alpha.776

### Patch Changes

- [#1053](https://github.com/rizom-ai/brains/pull/1053) [`fab1f73`](https://github.com/rizom-ai/brains/commit/fab1f73985b8fc7f63f332f252d233b20c5f4be5) Thanks [@yeehaa123](https://github.com/yeehaa123)! - A brain can talk on Matrix. The chat interface gains a `matrix` platform on Beeper's Chat SDK adapter, configured by `MATRIX_BASE_URL`, `MATRIX_USER_ID` and `MATRIX_PASSWORD`; it answers direct messages, posts approvals as text, and delivers invitations and notifications to a Matrix user by DM. The new `matrix` bundle adds the `matrix-server` plugin, which fronts a Tuwunel homeserver at the brain's own domain: it forwards `/_matrix`, serves the Matrix well-known documents, registers the brain's bot, and lets people sign in to the homeserver with their brain account, which records their Matrix id as theirs. Each peer brain trusted at `trusted` gets a room open only to the two servers, and the bot joins a room only when a trusted peer's bot invites it. A provisioned OAuth client can declare the identity its sign-ins prove, a notification recipient can be a Matrix user, and `a2a:peer-trust-changed` is broadcast when a peer's trust changes.

## 0.2.0-alpha.769

### Patch Changes

- [#1028](https://github.com/rizom-ai/brains/pull/1028) [`f388015`](https://github.com/rizom-ai/brains/commit/f3880158840d002dfd99e8f776302f36b63b2a76) Thanks [@yeehaa123](https://github.com/yeehaa123)! - A brain mounted as a drive and opened as an Obsidian vault keeps the vault's settings. Obsidian's `.obsidian` folder was a temporary item like any other hidden folder, gone ten minutes after its last use and on every restart, so the vault forgot its open tabs, settings and plugins. It is now stored per person with the brain's runtime state, 32 MiB at most, and is there after a restart and from that person's other devices. Other hidden folders stay temporary.

  Renaming a note's file on the drive renames the note. The brain had no rename: a file name was an id fixed at creation, and the drive refused the request, which left a mount showing a name the brain did not have. A note is now renamed in one step that keeps its text, metadata, visibility, creation date and embedding, announced as `entity:renamed` rather than as a delete and a create. Its file in `brain-data/` moves with it. Other types keep their names.
