Proposed

The header is for going, not for naming

Browse Studio spends the display face saying what the screen already is, and the chrome line 25px above it already names where you are. The header now holds the one thing you came for — a filter over every destination — and the way out.

Close was accent-coloured mono text, the loudest element on the screen. It becomes a quiet 44px ✕, matching the Conversations sheet, because leaving is not the thing you came here to do.

Single destinations come before the toggles

Today the order is Overview, Chat, LIBRARY, WORK, Admin, SYSTEM — so Admin, a direct destination, sits directly beneath a collapsed WORK and reads as its only child.

Every single destination sits above the toggles, in one block separated by a rule. A lone row wedged between two group headers reads as the tail of the group above it, whichever slot it holds, so position alone cannot carry the distinction.

A group header looks like a control

The header is an 8px muted uppercase caption with a 10px + at the far edge, yet it is the primary control of the sheet. Tracked capitals are the product’s caption grammar — right for the desktop leaf labels nobody taps, wrong for a control. It becomes a full-width 44px row set in sentence case like the rows it opens, chevron leading.

Groups rest open. Collapsing is explicit, and a collapsed group shows the destination you are in so the trail survives the fold.

One slot, two meanings, two treatments

Overview 2 and Admin 1 are attention counts; Field notes 54 and Documentation 7 are item tallies. Today they share a position and a type treatment.

Attention is set in the accent; a tally stays in the faint tone. Same slot, but the two no longer read alike — and no filled pill competes with the current-destination mark.

The empty half earns its keep

With three of four groups folded, content ends around 600px of an 844px screen and you still cannot see Work or System without two taps.

Groups rest open, so the sheet fills with what it is for. The filter narrows destinations as you type — the phone equivalent of ⌘K, which the phone chrome does not carry — and a folded group still names the destination you are in, so the trail survives the fold.

What this keeps

The decided grammar is unchanged: Browse replaces both rail levels at phone width, direct destinations sit above independently collapsible groups, there is no second dock, and Account stays with the profile menu rather than gaining an entry here. This is the same sheet with its hierarchy made visible.

Entering a destination still closes the sheet and never discards a draft, and admitted workspace attention counts stay available.
