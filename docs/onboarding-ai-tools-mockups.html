Connect AI tools you already use to this brain. A connected tool talks to the brain as you do in chat — asking, saving and updating within your access — after you sign in with your passkey.

Your brain’s address

https://becca.rizom.ai/mcp

Claude

Desktop app and claude.ai.

  1. Open Settings → Connectors → Add custom connector.
  2. Paste your brain’s address.
  3. Sign in with your passkey when asked.

ChatGPT

  1. Open Settings → Apps & Connectors → Advanced and turn on Developer mode.
  2. Choose Create, paste your brain’s address and pick OAuth.
  3. Sign in with your passkey when asked.

Claude Code

Run this in your terminal, then type /mcp to sign in.

claude mcp add --transport http brain https://becca.rizom.ai/mcp

Cursor

Add this to ~/.cursor/mcp.json, then sign in when Cursor asks.

{ "mcpServers": { "brain": { "url": "https://becca.rizom.ai/mcp" } } }

VS Code

Add this to .vscode/mcp.json, then sign in when VS Code asks.

{ "servers": { "brain": { "type": "http", "url": "https://becca.rizom.ai/mcp" } } }

Any other AI tool

If it supports MCP with OAuth: add a remote server with your brain’s address and sign in with your passkey.
