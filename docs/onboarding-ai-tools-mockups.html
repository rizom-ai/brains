Claude

Desktop app and claude.ai.

  1. Open Settings → Connectors → Add custom connector.
  2. Name it becca-rizom-ai and paste your brain’s address.
  3. Sign in with your passkey when asked.

ChatGPT

  1. Open Settings → Apps & Connectors → Advanced and turn on Developer mode.
  2. Choose Create, name it becca-rizom-ai, paste your brain’s address and pick OAuth.
  3. Sign in with your passkey when asked.
Developer tools and other clients Claude Code, Cursor, VS Code, any MCP client

Claude Code

Add the server in your terminal:

claude mcp add --transport http becca-rizom-ai https://becca.rizom.ai/mcp

Then start Claude Code, run /mcp, choose becca-rizom-ai and sign in with your passkey.

Cursor

  1. Open Cursor Settings → MCP → Add new global MCP server.
  2. Name it becca-rizom-ai and paste your brain’s address.
  3. Sign in with your passkey when Cursor asks.

Or add it to ~/.cursor/mcp.json:

{
  "mcpServers": {
    "becca-rizom-ai": {
      "url": "https://becca.rizom.ai/mcp"
    }
  }
}

Already have servers there? Add only the "becca-rizom-ai" entry inside "mcpServers" of the file.

VS Code

  1. Open the Command Palette and run MCP: Add Server.
  2. Choose HTTP, paste your brain’s address and name it becca-rizom-ai.
  3. Choose Global, then sign in with your passkey when asked.

Or run MCP: Open User Configuration and add:

{
  "servers": {
    "becca-rizom-ai": {
      "type": "http",
      "url": "https://becca.rizom.ai/mcp"
    }
  }
}

Already have servers there? Add only the "becca-rizom-ai" entry inside "servers" of your user configuration.

Any other MCP client

Look for “add MCP server”, “connector” or “integration” in the tool’s settings and fill in:

Name
becca-rizom-ai
Type
Remote server, Streamable HTTP — not stdio, not SSE
URL
https://becca.rizom.ai/mcp
Authentication
OAuth. Leave API key, token, client ID and secret empty; the tool registers itself.

When you connect, your browser opens “Authorize <tool>?” on your brain. Approve MCP access with your passkey. The tool then has two tools: chat, to ask your brain anything as you would in chat, and confirm, to approve changes when the brain asks.

Tool only takes local (stdio) servers, or insists on an API key? Bridge it with mcp-remote, which handles the sign-in: 

{
  "mcpServers": {
    "becca-rizom-ai": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://becca.rizom.ai/mcp"
      ]
    }
  }
}
