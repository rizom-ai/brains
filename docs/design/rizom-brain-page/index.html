01 · Answers

Ask it what you know.

Ask it to find relevant material, explain an idea or develop a draft. Keep source references close so you can check its answer.

Use its own chat, or connect Claude Desktop, Cursor and any other MCP client. One brain behind all of them.

AI can still be wrong. The sources are there so you can check.

02 · Capabilities

Equip it for your kind of work.

Core is always on: your profile, notes and links, topics, an inbox, MCP, and an identity other agents can address.

Everything else is a line in brain.yaml. Switch on chat, a public site, publishing, playbooks or team memory when your practice needs it. Switch it off just as easily.

Something particular to you is a plugin. Plugin authoring ↗

03 · Collective

Different knowledge. Shared work.

Your collaborators’ brains bring knowledge yours doesn’t have. Use their contributions to develop shared work, while each person or team keeps their own agent and knowledge.

Agent-to-agent calls make that exchange possible. Public profiles help you find relevant knowledge; access policies govern what a brain shares.

People choose the work and review contributions. A connection is a starting point, not a finished collaboration. Explore the network ↗

04 · Stays yours

Own the agent. Not rent it.

Keep your knowledge in portable files. Run and extend the software yourself. Choose your providers—and change them without starting your knowledge base over.

Files you can take with you.

Your notes and other text records are portable markdown with frontmatter. Version them with git; read them without the brain running.

Your server, your model.

Run the brain on your own server and choose its AI provider. Cloud models still process requests with that provider.

A commons, not a cage.

The runtime uses AGPL-3.0; SDK and contract packages use Apache-2.0. You can inspect, modify and contribute to the software.

Quick start

Start with your own material.

Install Bun, then bring a folder of your own notes. The first useful question does not need a tidy archive.

terminal@rizom/brain
# install
$ bun add -g @rizom/brain
# create
$ brain init mybrain --recipe personal
$ cd mybrain
$ cp .env.example .env   # set AI_API_KEY
# run
$ brain start
