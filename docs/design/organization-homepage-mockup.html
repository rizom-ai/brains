About this mockup

The professional homepage's frame, type, marks, title cards and legend, with the radar where the landscape was. The scope stays quiet: range rings for how close an agent's work runs to ours, and bearing ticks on the edge. The professional site's contour line appears only where there is signal: each constellation is an echo, stacked lines wrapped around its agents and pinched along the thread between them, with its name set across it, and each lone agent is a small island. Every agent is named beside its blip; an agent awaiting review is an outline with a dashed echo. The one motion is a pulse radiating from the team every nine seconds: each echo and agent lights as the wave reaches it, so what is closest to our work lights first.
