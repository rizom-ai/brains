Also changed

  1. No "Full chat ↗" in the phone sheet. The sheet already fills the screen, and the header no longer changes when the first answer arrives.
  2. One map, one size. The strip is a window onto the same map as the page, at the same size, not a second map drawn larger. An answer zooms the map once, and the page and the strip share that zoom, so opening and closing never rescale it. Marks keep their size when the map zooms; a lit piece is always one and a half times a plain mark.
  3. One set of motions. Rise and fall for the sheet, fold for the strip, one fade for an arriving answer. Nothing else moves. Reduced motion turns all of them off.
  4. Focus follows the visitor. The composer takes focus only while the sheet is open, so a closed sheet never reopens on its own.
