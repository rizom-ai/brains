Also changed

  1. No "Full chat ↗" in the phone sheet. The sheet already fills the screen, and the header no longer changes when the first answer arrives.
  2. One map, one size. The conversation shows the page's own map at the page's height, and only its window shrinks as the answer scrolls. An answer zooms the map once, and the page and the strip share that zoom, so opening and closing never rescale it. Marks keep their size when the map zooms; a lit piece is always one and a half times a plain mark.
  3. The answer and the map point at each other. Desktop draws leads from each source to its mark; a phone has no room for lines, so a source takes you to its piece, and a piece takes you to its source.
  4. One set of motions. Rise and fall for the sheet, the map following the answer's scroll, one fade for an arriving answer. Nothing else moves. Reduced motion turns all of them off.
  5. Focus follows the visitor. The composer takes focus only while the sheet is open, so a closed sheet never reopens on its own.
