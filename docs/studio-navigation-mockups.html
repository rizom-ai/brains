Direction A · Bound index

One rail, explicit focus

A familiar document index with independently scrolling groups. It is the quieter and lower-risk direction.

  • Never disappears automatically. Collapse is a deliberate user action.
  • Groups stay visible but may be folded.
  • Best when users move frequently across unrelated areas.

Direction B · Area + leaf

Stable place, contextual list

A compact primary map paired with a contextual destination list. It gives a large Studio clearer information architecture.

  • System is a place, not a visual exception.
  • Explicit collapse leaves a 68px area strip; labels and the leaf return on expansion. Accessible names and hover labels remain available.
  • Selecting an area reopens its leaf. Changing documents does not undo your collapse choice.
  • Mobile opens the current group by default. Groups fold independently; the dock opens and scrolls to a group without leaving the working document.
