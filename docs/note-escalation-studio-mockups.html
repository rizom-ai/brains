Refining notes from the library

Pick loose notes in the Notes list and refine them into one. The flow and its words are the ones chat uses: one confirmation that names the notes and says they will be removed.

01

The list at rest

Nothing is added to the page. The row number is where a note is picked: under the pointer, or with keyboard focus, it becomes a mark.

New note stays the page's one action. A caller who may not delete notes never sees the mark.

02

Notes picked

Once a note is picked, every row shows its mark and the count takes the place of the sort line.

The page still has one action: New note gives way to Refine 3 notes. One picked note reads Refine note. Cancel, or Escape, puts the list back.

On a phone the action sits in the action bar, where the page's action always is.

03

One confirmation

The same question chat asks: it names every note and says they will be removed. Nothing is written or removed before Refine.

The direction is optional. Left empty, the brain writes from the notes alone. It is also read for where the refined note belongs.

05

Done

The entry takes the title the brain wrote. The line above the list says what happened, once, and names what was removed.

Notes is three entries shorter. The refined note opens in the ordinary editor, where its summary and its grouping are properties like any other.

06

When it fails

The brain could not write it: the entry is marked failed with the reason, and every note is still in Notes.

A note could not be removed: the refined note is kept, and the line names the note that is still there.
